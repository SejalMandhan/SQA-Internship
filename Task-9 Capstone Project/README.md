# HisabDo – Day 9 Capstone Project | SQA

## 📌 Project Overview

This repository contains the **Day 9 SQA Capstone Project** for the **HisabDo application**.

The main objective of this project was to convert the Day 8 test planning into **detailed and executable test cases** for both the mobile application and website.

## 🧪 Testing Scope

The following areas were covered:

- Login & Authentication
- Forms & Validation
- Navigation
- CRUD Operations
- Reports
- Settings
- Error Handling
- UI/UX
- Boundary Testing
- Negative Testing

## 📱 Mobile Application

- 20+ detailed test cases
- Functional testing
- Validation testing
- Navigation testing
- CRUD testing
- Reports testing
- Settings testing
- Negative and boundary testing
- UI/UX testing

## 🌐 Website

- 15+ test cases
- Login & authentication
- Forms & validation
- Navigation
- UI/UX
- Error handling
- Negative testing
- Boundary testing

## 📝 Test Case Format

Each test case contains:

- Test Case ID
- Module
- Test Scenario
- Preconditions
- Test Steps
- Test Data
- Expected Result
- Actual Result
- Status
- Priority

## ▶️ Test Execution

At least **10 test cases were executed** and the actual results were recorded.

Test cases were marked as:

- **Pass** – Actual result matched the expected result
- **Fail** – Actual result did not match the expected result
