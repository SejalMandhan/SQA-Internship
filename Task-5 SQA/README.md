# 📌 Complete API Test Suite Using Postman

## 🎯 Objective

The objective of this task is to build a comprehensive **API Test Suite** using **Postman** by performing functional testing, validation testing, response verification, automated assertions, and documenting test cases and API issues.

---

# 🌐 Public API Used

### JSONPlaceholder REST API

**Base URL**

```
https://jsonplaceholder.typicode.com
```

JSONPlaceholder is a free online REST API used for learning, testing, and prototyping API requests.

---

# 🧪 Testing Scope

## ✅ Functional Testing

The following API operations were tested:

- 📄 GET All Records
- 🔍 GET Single Record
- ➕ POST Create Record
- ✏️ PUT Update Record
- 📝 PATCH Update Partial Record
- 🗑️ DELETE Record

---

## ✅ Validation Testing

Validation scenarios included:

- ❌ Missing Required Fields
- ❌ Invalid Record ID
- ❌ Empty Request Body
- ❌ Invalid Data Types
- ❌ Incorrect API Endpoint
- ❌ Duplicate Data (where applicable)

---

## ✅ Response Validation

Each API response was verified for:

- HTTP Status Code
- Response Body
- Required Fields
- Data Types
- Response Time
- Error Messages

---

## 🤖 Postman Test Scripts (Assertions)

Basic automated assertions were created to validate:

- ✅ Status Code
- ✅ Response Time
- ✅ Response Body
- ✅ Required Fields
- ✅ Data Types
