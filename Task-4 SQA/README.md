# 📌 REST API Testing Using Postman

## 🎯 Objective

The purpose of this task is to practice **REST API Testing** using **Postman** by performing CRUD operations (**GET, POST, PUT, PATCH, DELETE**), executing negative test scenarios, validating API responses, documenting test cases, reporting bugs, and capturing test evidence.

---

## 🌐 Public API Used

### JSONPlaceholder

**Base URL:**

```
https://jsonplaceholder.typicode.com
```

JSONPlaceholder is a free fake REST API used for testing and prototyping.
