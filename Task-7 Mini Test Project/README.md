# Mini Test Project

## Project Summary

This project focuses on testing an e-commerce shopping application from a QA Engineer's perspective. The testing covers the complete shopping journey, including user login, product browsing, product selection, shopping cart, checkout, form validation, and order completion.

The project also includes API testing using Postman to validate product-related API endpoints and responses.

## Application Tested

**Web Application:** SauceDemo  
**API:** DummyJSON Products API  
**Tool:** Postman

## Testing Performed

- Functional Testing
- UI Testing
- Form Validation
- Positive Testing
- Negative Testing
- Boundary Testing
- API Testing
- Usability Testing
- Cross-Browser Testing

## Main Modules Tested

### Login
- Valid login
- Invalid login
- Empty username and password
- Login validation messages

### Products
- Product display
- Product details
- Product prices
- Product sorting
- Add to Cart functionality

### Shopping Cart
- Add products
- Remove products
- Cart item count
- Product information verification

### Checkout
- Checkout form validation
- Required field validation
- Order overview
- Order completion

### API Testing

Product APIs were tested using Postman, including:

- Get all products
- Get a single product
- Invalid product requests
- Search products
- Product categories
- Products by category
- Limit and skip parameters
- Response validation
