# 🚀 Authentication API Testing

## 📖 Overview

This repository contains an **Authentication API Testing** project completed as part of the **SQA Internship Program – HisabDo**.

The project focuses on testing authentication, authorization, validation, security scenarios, and API responses using Postman.

---

## 🌐 APIs Used

### ReqRes API
Used for registration and login testing.

**Base URL:**  
https://reqres.in

### DummyJSON API
Used for authentication token and protected endpoint testing.

**Base URL:**  
https://dummyjson.com
